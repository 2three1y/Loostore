# Loostore

Every app and project by Carter, in one place: https://2three1y.github.io/Loostore/

The list lives in one file, [catalog.json](catalog.json). Each entry uses the app manifest keys from Looscid OS (`id`, `name`, `version`, `category`, `summary`), plus `url` (where the app opens), `source` (its code) and `live` (false when there is no live site yet, so `url` is the source code).

To add an app, add an entry to catalog.json and a matching item to index.html.
